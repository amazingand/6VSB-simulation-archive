# 历史快照

`archive/` 保存输入文件、脚本、RST 约束文件及相关工程文档的历史版本。快照只增不改；当前部署版本位于 `protocols/`。

每个可恢复快照应包含：

- `MANIFEST.tsv`：规范路径、大小和 SHA-256；
- `SOURCE_ARCHIVES.tsv`：原传输容器及其 SHA-256；
- `SOURCE_MEMBERS.tsv`：原成员路径到规范路径的逐文件映射。

目录说明：

- `S0_20260811_construct-X_sources/`：两个大型原始来源包的清单映射，不重复保存约 1 GB 的展开内容；
- `P1_...`：仅有恢复说明，没有独立文件容器；
- `P2_...`：从历史整合包重建的两个系统快照；
- `P3_...`：三个权威容器展开后的系统与 core 快照；
- `P4_...`：权威 P4 展开树及较早说明变体；
- `non_delivery/`：已经确认版本、但不属于正式交付链的草稿或暂存对象；
- `文档旧版/`：被替代的版本化文档。

历史传输压缩包暂时保留在原路径，但不进入本目录。最终删除将在完整重新检出验证后另行决定。
