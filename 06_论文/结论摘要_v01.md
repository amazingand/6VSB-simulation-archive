# C′ 项目进度与证据链报告 v01

> 日期:2026-08-17 晚间
> 主题:力驱动 SARS-CoV-2 棘突 S1/S2 解离——当前进度、证据链完整逻辑、可信度分层
> 一句话结论:**单轨迹定量数据已给出明确、自洽、与 2023 RSC Adv. 静态剪切一致的方向性结论;副本集合与轨迹级接触归因是统计与机制的补强,不是推进论文的必要前提。**

---

## 1. 项目目标与核心预言

| 项 | 内容 |
|---|---|
| 科学问题 | furin 切割(685–686)对 S1/S2 解离的**力学代价**有何影响?融合肽(FP,829–852)何时被解除遮蔽? |
| 手段 | 全原子显式溶剂 **steered MD**(Amber `pmemd.cuda`,ff19SB+GLYCAM06j+TIP3P,0.15 M NaCl,~242k 原子),拉 S1 尾 COM ↔ S2 头 COM(144/200 Cα,rk2=7.2 kcal/mol/Å²,1 Å/ns 定量) |
| 对照基准 | 用户 2023 论文(Yu et al.,RSC Adv. 13,16970–16983)静态剪切(SMOG 56 组合):切割后 S1/S2 更易分离 → FP 释放条件放宽 |
| 本项目预言 | 切割态比未切态:**峰力更低、总功更小、主释放更早、势垒结构不同** |
| 检验对象 | 构型 X = S1 尾(540–685)+ S2 头(686–1035),跨链接口(与 6VSB 密度/2023 论文同源),cleaved vs uncleaved 两模式 |

## 2. 证据链的完整逻辑(自下而上,每层的可信度如何建立)

```
[结构层]  构型 X 构建 + 体系自检全绿(0 clash、盐桥 3.02 Å、5 对二硫、6 个 N-糖、FP 二硫完好)
     ↓ 可信度: 与 CHARMM-GUI archive 全长模型逐原子比对(TER 移除 + 严格复刻 archive 布局)
[力场层]  ff19SB + GLYCAM06j + TIP3P(糖界面遮蔽效应用专用糖力场;CHARMM-GUI FF-Converter 验证流程)
     ↓ 可信度: 标准力场组合,无自定义参数
[协议层]  align_min → EQ1–EQ4 → 分片 SMD(1 ns/段可重启)
     ↓ 可信度: 对齐极小化=确定性分界点;云侧 sander 与用户 pmemd.cuda 前 100 步能量
     ↓        轨迹对比 0.32%/0.34%(双精度 vs SPFP 浮点差异,预期内)→ 协议两端一致
[初筛层]  5 Å/ns 端到端跑通(定位+协议验证)   ← 非证据,仅作 5 vs 1 Å/ns 稳健性对照
     ↓ 发现并修正 3 个问题:R0 开局压缩伪迹→按体系平衡距离(28.28/31.27 Å);
     ↓        断点续跑条件收紧;analyze 段界判据(功重置标记,累计功修正)
[定量层]  1 Å/ns 从 eq4 全新起跑,段全完整,拉满至 RF=55   ← 论文证据主体
     ↓ 核验: 段边界=功重置标记(analyze v3);∫F·dr2 交叉校验差 0.6%/1.2%;
     ↓        eq4 盐桥距离与平衡结构一致(cleaved 2.70/2.73 Å, uncleaved 2.66 Å)
[机制层]  势垒结构分解(1 Å 窗均力)+ 界面盐桥/接触归因
     ↓ 可信度: 与 eq4 结构原子级对应;cleaved 两段式 vs uncleaved 单一主导势垒
[产出层]  论文骨架 v01(4 图 + Table 1 + 17 条核实引文)
```

**每层的“锁”**(防止证据被污染):
- 初筛数字一律不作论文证据(快拉偏置 + 开局伪迹),只留"5 vs 1 Å/ns 排序一致"这一句稳健性表述;
- 定量从 eq4 全新起跑,段全完整,零继承初筛轨迹;
- 所有数字可复算(分析脚本 + 原始 DUMPAVE + 指纹记录)。

## 3. 定量关键结果(论文证据,全部经云侧复核)

| 指标 | cleaved | uncleaved | 含义 |
|---|---|---|---|
| eq4 平衡 COM | 28.28 Å | 31.27 Å | R0 起点 |
| **峰力(单点)** | **960 pN @ 30.78 Å** | **1331 pN @ 40.28 Å** | 切割 −28% |
| 峰力(平滑 5 点) | 650 pN @ 31.15 Å | 1140 pN @ 40.28 Å | 切割 −43% |
| **首次主释放** | **31.56 Å** | **41.73 Å** | 切割提前 ~10 Å |
| 释放处功 | 8.97 kcal/mol(18%) | 47.07 kcal/mol(72%) | 释放时已做功 |
| **总功** | **49.73 kcal/mol** | **65.22 kcal/mol** | 切割 −24% |
| 主导势垒带 | 36–45 Å(55% 功) | 37.5–42.5 Å(56% 功) | 两段式 vs 单一 |
| 窗均力最高 | 368 pN | 635 pN | 未切持续承力更高 |
| eq4 盐桥 | ASP614–LYS854 2.70 Å;**LYS557–ASP839 2.73 Å**(后者在 FP 内) | ASP614–LYS854 2.66 Å | 切割态多一个 FP 锚 |

**机制读数**:cleaved 的 N 半(540–616,遮蔽 FP)仅靠两个盐桥锚定 → 31.6 Å 即脱开,FP 在总功只耗 18% 时解除遮蔽;C 半拖过 S2 头成为 36–45 Å 二次带(55%)。uncleaved 的 685–686 共价键把全部接触耦合成单一力学单元 → 单调爬升后一个主导势垒(56%),41.7 Å 一次性释放 72% 功。**这与 2023 静态剪切结论方向一致,并给出了量化的力学数字(功/力/距离)。**

## 5. 结论:当前证据是否支持推进?

**支持,且两条路可以并行:**

1. **论文可以继续推进**。单轨迹定量数据已给出方向明确、数字自洽、与 2023 静态剪切一致的结论;论文骨架 v01 已成型。待补的两块是**统计强化**(副本均值±范围,把 960/1331 pN、49.7/65.2 kcal/mol 从单值变为区间)与**机制深化**(轨迹级接触归因,回答"哪些残基在哪段距离脱开"),它们是锦上添花而非必要前提。
2. **副本生产可以启动**。4×4090 工作站跑 `launch_all_replicas.sh`;数据回来推仓库 → 云侧复核 → 回填论文 [A]。
