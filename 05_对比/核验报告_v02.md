## 2. 关键结果(定量, v3)

| 指标 | cleaved | uncleaved |
|---|---|---|
| 单点拉伸峰力 | 13.82 kcal/mol/Å ≈ **960 pN** @ COM 30.78 Å(t≈3.5 ns) | 19.16 ≈ **1331 pN** @ COM 40.28 Å(t≈10.3 ns) |
| 5 点平滑峰力 | 9.36 ≈ **650 pN** @ COM 31.15 Å | 16.41 ≈ **1140 pN** @ COM 40.28 Å |
| **首次主释放**(峰后 <30%) | COM ≈ **31.6 Å**,功 **8.97 (18%)** | COM ≈ **41.7 Å**,功 **47.07 (72%)** |
| 释放点之后的最大力 | **859 pN(峰值 90%)** @ r2 39.2 Å | 1008 pN(峰值 76%) @ r2 43.1 Å |
| 累计功(Σ 分片) | **49.73 kcal/mol ≈ 208 kJ/mol** | **65.22 kcal/mol ≈ 273 kJ/mol** |
| ∫F·dr2 交叉校验 | 50.02(差 0.6%) | 66.01(差 1.2%) |
| 抗阻最强分片 | r2 31.28–32.28 Å, 6.07 kcal/mol | r2 41.27–42.27 Å, 10.06 kcal/mol |

**对照要点**:

- **功**: uncleaved 比 cleaved 高 **31%**(65.2 vs 49.7 kcal/mol);
- **峰力**: uncleaved 比 cleaved 高 **38%**(1331 vs 960 pN;平滑峰 1140 vs 650 pN,
  差 75%——cleaved 峰为单点尖峰,平滑后大幅回落);
- **首次主释放位置**: cleaved 在 COM ~31 Å;uncleaved 延展至 COM ~42 Å(推迟 ~10 Å),
  且主释放承载的功占比差异巨大(18% vs 72%,见 §4 与机制分析报告)。

> 注:cleaved 的"首次主释放"并非最终分离——其后力回升、二次抗阻带(36–45 Å)承担
> 55% 的功(见 `docs/M3_机制分析_v01.md` §2–§3)。

## 3. 与初筛(5 Å/ns)的对照——定性一致性检验

初筛数字为**协议验证与假设生成,非论文证据**;此处仅检验定性排序是否稳健。

| 指标 | cleaved 5 Å/ns | cleaved 1 Å/ns | uncleaved 5 Å/ns | uncleaved 1 Å/ns |
|---|---|---|---|---|
| 首次主释放距离 | 30.1 Å | 31.6 Å | 42.1 Å | 41.7 Å |
| 累计功 | 71.15 | 49.73 | 96.01 | 65.22 |
| 单点峰力 | 1068 pN | 960 pN | 1016 pN* | 1331 pN |

*初筛 uncleaved 为 R0=28.80(非平衡 31.27),开局弹簧压缩 −35.6 kcal/mol(≈2475 pN),
峰值统计前已排除该伪迹;初筛峰力 1016 pN 为修正后拉伸峰。

**结论**:

1. **主释放距离次序、功次序在两种拉速下完全一致**: uncleaved 均更晚释放、功更高
   ——定性结论稳健。
2. **拉速效应符合预期**: 功随拉速降低而下降(耗散减小,更接近可逆功),cleaved
   71.2→49.7、uncleaved 96.0→65.2 kcal/mol。
3. **峰力排序翻转**(初筛 cleaved 1068 > uncleaved 1016;定量 uncleaved 1331 > cleaved 960)
   归因于三因素: 初筛 uncleaved 开局压缩伪迹、R0 由 28.80 修正为体系平衡值、
   以及慢速下 uncleaved 界面充分延展形成的持续高力平台。峰力为单点量、涨落敏感,
   **不以峰力排序作论文结论**,以功与主释放距离为准。

## 4. 科学结论与对 2023 RSC Adv. 的呼应

**S1/S2 切割态(furin cleaved)的 S1 尾更容易被剥离,FP 更容易释放。**

- **cleaved 是两段式释放**: S1 尾 N 端一半(含 FP 遮蔽接触 K557–D839、F592、D614)
  在 COM ~31 Å 先脱开(960 pN 尖峰、平滑 650 pN)——**FP 遮蔽在 ~9 kcal/mol(总功 18%)
  即解除**;S1 尾 C 端一半仍抓住 S2 茎区,随拉动在 36–45 Å 形成二次抗阻带(力回升至
  峰值 90%,窗均力最高 368 pN,承担 55% 的功),至 ~45 Å 才完全脱离。
- **uncleaved 是单一主导势垒**: 685–686 共价连接迫使整条 S1 尾协同延展,抗力随拉伸
  累积,在 COM ~40–42 Å 集中爆发(1331 pN、平滑 1140 pN、窗均力 635 pN、主释放承载
  72% 功),需要显著更高功才能剥离 S1 尾。
- 与 2023 年 RSC Adv.(Yu et al.)静态剪切模型**定性一致**: furin 切割(以及 S1 剥脱)
  后 FP 释放所需抗力显著降低,为融合前构象的 FP 释放铺平道路。机制细节(两段式 vs
  单一势垒、界面盐桥归因)见 `docs/M3_机制分析_v01.md`。

证据边界: §2 的定量数字进入论文; §3 初筛仅作稳健性对照(或 Methods 一句排查说明);
残基级归因为平衡结构几何假说,轨迹级确认见机制分析报告 §7。

## 5. 分析脚本修正:v2 → v3(重要)

生产数据核验中发现 v2 段边界判据在慢速下漏检边界导致**累计功低估**
(cleaved 45.5→49.7, uncleaved 62.9→65.2)。已修正为 v3:
段起点 = **DUMPAVE 功精确为 0 的行**(每 run 从 0 重置的确定性标记),与力幅/拉速
无关;并新增 5 点平滑峰与 ∫F·dr2 交叉校验。详见
`history/P5_20260817_analyze_v3功修正/说明.md`。
