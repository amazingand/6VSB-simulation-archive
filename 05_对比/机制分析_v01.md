# M3 · 机制分析:力驱动解离的势垒结构与界面归因

> **一句话结论**:定量 SMD(1 Å/ns)揭示两种 S1/S2 切割态的 S1 尾解离**不是同一类过程**——
> **cleaved 是两段式释放**(~31 Å 首次主释放只占总功 18%,力随后回升至峰值的 90%,
> 36–45 Å 二次抗阻带承担 62% 的功);**uncleaved 是单一主导势垒**(37.5–42.5 Å 带占
> 56% 的功、持续均力 344–635 pN)。界面平衡接触归因给出结构基础:cleaved 的 S1 尾
> N 端一半直接锚定融合肽(额外盐桥 LYS557–ASP839),C 端一半仍抓住 S2 茎区;uncleaved
> 的 685–686 共价连接迫使整条尾协同延展,抵抗在最大伸长约 40 Å 处集中爆发。**结论与
> 2023 RSC Adv. 一致且更具体:furin 切割使 S1 尾能在更小分离(~31 Å)、更低持续力下
> 释放融合肽遮蔽。**
>
> 报告日期: **2026-08-17**;数据: 定量 smd.out(1 Å/ns,证据)+ eq4 平衡结构。

---

## 1. 数据与方法

本报告全部数字来自**定量(1 Å/ns)**的 `smd.out`(分析脚本 analyze_smd.py v3,段边界
以功重置标记 w==0 精确定位)与**eq4 平衡结构**(SMD 起点):

| 输入 | 位置 |
|---|---|
| 力-位移/功数据 | `analysis/{cleaved,uncleaved}_smd_prod_v01.dat` |
| eq4 平衡结构 | `tmp/smd_check/eq4/{cleaved,uncleaved}_eq4.rst7`(Cα COM 距离复算 28.22 / 31.21 Å,与 SMD 起点 28.28 / 31.27 一致) |
| 原子–残基映射 | CHARMM-GUI `step3_input.pdb`(保留 PDB 残基号)+ parm7 |

方法:
- **势垒结构**:按 1 Å COM 窗口统计窗内均力(持续抗力)、窗内极大(瞬态峰值)与窗功。
- **功分布**:段功按窗口累加;首次主释放节点按 analyze v3 判据(峰值后力首次 <30% 峰值)。
- **界面接触**:eq4 几何下 S1 尾(540–685)↔ S2 头(686–1035)重原子最近距离;
  盐桥 = 侧链 O…N < 4.0 Å;极性接触 = 重原子 < 3.5 Å(排除盐桥)。

## 2. 修正的势垒结构:cleaved 两段式 vs uncleaved 单一主导

`analysis/smd_prod_barrier_architecture_v01.png` 给出两体系 1 Å 窗口的持续力(均值棒
+ 窗极大须)与累计功。量化结构:

| 体系 | 阶段(COM 窗口) | 窗均力范围 | 窗极大范围 | 窗口功 | 占总功 |
|---|---|---|---|---|---|
| **cleaved** | Ⅰ 首次释放 30.3–32.3 Å | 246–399 pN | 752–960 pN | ~9.1 | 18% |
| | (松弛带 32.3–36.5 Å) | ~10–70 pN | 474–569 pN | +1.7 | — |
| | **Ⅱ 二次抗阻带 36.3–45.3 Å** | 128–368 pN | 604–859 pN | ~27 | **55%** |
| | 尾段 45.3→55 Å | <157 pN | ≤736 pN | +4.1 | 8% |
| **uncleaved** | 爬升带 32.3–37.5 Å | 169–278 pN | 494–829 pN | 16.8 | 26% |
| | **主导势垒 37.5–42.5 Å** | 344–**635** pN | 829–**1331** pN | 36.8 | **56%** |
| | 收尾 42.5–44.3 Å | 197–376 pN | 744–1008 pN | ~5.4 | 8% |

要点:

1. **cleaved 的"解离"(~31.6 Å)不是终点**:首次主释放后力**回升至峰值的 90%**
   (859 pN @ r2=39.17 Å),36–45 Å 二次抗阻带累计 ~27 kcal/mol、占总功 55%——
   S1 尾并未整体脱离,而是**分段释放**(详见 §5)。
2. **uncleaved 的持续抗力最强**:最强窗口(40.3–41.3 Å)窗均力 635 pN(cleaved 最强窗
   399 pN),且 37.5–42.5 Å 主导带占 56% 功——单一、集中、延展型抵抗。
3. **总功次序**(uncleaved 65.2 > cleaved 49.7,+31%)主要来自主导带的存在本身,而非
   持续更高的一般性抗力。

## 3. 功分布与"首次主释放"节点

| 指标 | cleaved | uncleaved |
|---|---|---|
| 单点峰力(证据) | 960 pN @ COM 30.78 Å(r2 31.74) | 1331 pN @ COM 40.28 Å(r2 41.61) |
| 首次主释放(峰值后 <30%) | COM 31.56 Å,已做功 **8.97 (18%)** | COM 41.73 Å,已做功 **47.07 (72%)** |
| 释放点之后的最大力 | **859 pN(峰值的 90%)** @ r2 39.17 | 1008 pN(峰值的 76%) @ r2 43.10 |
| 平滑(5 点)峰力 | 650 pN @ 31.15 Å | 1140 pN @ 40.28 Å |
| 累计功 | 49.73 kcal/mol | 65.22 kcal/mol |

**解读**:对 cleaved,~31 Å 只是**第一个、且不是最大的**释放事件;把"解离完成"等同于
31.6 Å 会低估 82% 的做功。对 uncleaved,主峰本身承载了 72% 的功——峰与功高度一致,
是教科书式的单一主势垒。

## 4. 界面接触归因(eq4 平衡结构)

盐桥(侧链 O…N < 4.0 Å):

| 体系 | 盐桥 | 距离 | 位置注释 |
|---|---|---|---|
| cleaved | **LYS557–ASP839** | 2.73 Å | ASP839 **在融合肽 FP(829–852)内部**;S1 尾 N 端直接锚定 FP |
| cleaved | **ASP614–LYS854** | 2.70 Å | 2023 RSC Adv. 锚点;FP 下游侧翼 |
| uncleaved | **ASP614–LYS854** | 2.66 Å | 唯一盐桥,同样锚定 FP 侧翼 |

关键接触对(重原子最近距离 < 4.5 Å,节选;完整清单见分析脚本输出):

- **FP 遮蔽带(835–870)**:
  - cleaved: K557–D839, D614–K854/Q836/K835, F592–Q836/K854/F855, P589–F855,
    N616–Y837, V615–Y837, A647–P862, A668–P862/P863/T866, G667/G669/C671–L864/L865/T866/M869
  - uncleaved: D614–K854/T859/K835, Q613–L861/S735, P592–F855, F592–K854, V615–Y837,
    E619–Y837, R646/A647–P862/I834/K835, G667/A668–P862/P863/L864
- **下 S2 接触(745–754、928、963–967、1005–1029)**:
  - cleaved: A679–N928, I569–V963, A570–K964/S967, L582–Q1010
  - uncleaved: T549–D745, E554–Q1005, R567–M1029, Q628–L754, N657–T739, A570–S967, N679–N928

**要点**:
- 两体系共享 2023 锚点盐桥 ASP614–LYS854;**cleaved 额外以 LYS557–ASP839 直接把
  S1 尾 N 端拴在 FP 上**(ASP839 位于 FP 序列内)。
- S1 尾的**接触呈段式分布**:N 端一半(540–616)抓 FP 遮蔽带,C 端一半(617–685)抓
  S2 茎区(855–870)与下 S2(928 等)。这是 §5 分段释放假说的结构基础。

## 5. 解离机制假说

### cleaved:分段释放(two-segment release)

1. 平衡态 S1 尾 N 端一半(K557、P589、F592、D614、N616)遮蔽 FP;拉载后**首个事件
   即打破 FP 遮蔽带**(~31 Å,960 pN),S1 尾 N 端脱开,FP 开始暴露。
2. 但 S1 尾 C 端一半(647–685)仍抓住 S2 茎区(855–870、928)——随拉动被拖过 S2 头
   表面,在 36–45 Å 重新形成**二次抗阻带**(力回升至 859 pN,窗均力最高 368 pN),
   承担 55% 的功。
3. 直到 ~45 Å 全部接触解耦,尾段小幅拖动收尾。

→ **FP 遮蔽在 ~31 Å、以 18% 的功即被解除**,后续做功与 FP 释放无关(是尾拖出过程)。

### uncleaved:整体协同延展(single dominant barrier)

1. 685–686 肽键把 S1 尾 C 端**共价**连在 S2 头上——S1 尾无法像 cleaved 那样"先放
   N 端、再拖 C 端",整条尾必须作为一个装配体被拉开。
2. 力沿共价键传导到全部界面接触(FP 遮蔽带 + 下 S2 接触一起承力),抗力随拉伸单调
   累积,在**最大伸长约 40 Å**处集中爆发(1331 pN、窗均力 635 pN),占 72% 的功。
3. 主峰后 ~2 Å 内(42–44 Å)界面整体解除(肩峰 1008 pN 后快速回落)。

### 与 2023 RSC Adv. 的呼应(定性一致、机制更具体)

- 2023 静态剪切结论:furin 切割后 S1/S2 界面抗力降低、FP 更易释放。**定量 SMD 支持
  并细化**:
  - 切割态 FP 遮蔽在 **~31 Å、~9 kcal/mol** 即解除;
  - 未切割态须延展至 **~41 Å、~47 kcal/mol** 才能突破主势垒(**~5 倍功**,
    47.1 / 9.0 kcal/mol)。
- 差异的**来源是共价键**(685–686),而非简单界面接触数目:cleaved 界面盐桥数(2)
  反而比 uncleaved(1)多,但 uncleaved 的共价连接把全部接触耦合成一个整体势垒。

> 证据边界:§4/§5 的界面归因基于**平衡结构几何**(SMD 起点),40 Å 附近实际承力残基
> 需轨迹帧确认(见 §7)。功分布与势垒结构(§2/§3)为 smd.out 直接测量,无此限制。

## 6. 对《M3_SMD生产核验报告_v01》的叙事修正

核验报告 v01 §2/§4 的"cleaved 界面早期脆性滑脱(~31 Å)、解离随即完成"表述**不完整**:
31.6 Å 只是首次主释放(占总功 18%),力随后回升至峰值的 90%,36–45 Å 二次抗阻带承担
55% 的功。已出 v02 修正(首次主释放 vs 最终分离分开表述)。**总功与峰力数字、uncleaved
更难剥离的结论不变**。
