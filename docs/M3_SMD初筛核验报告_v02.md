# M3 SMD 初筛核验报告(5 Å/ns)

2026-08-15 · 项目 Cprime 棘突 S1/S2 力驱动解离
数据源: 用户本地 pmemd.cuda 初筛, GitHub `amazingand/6VSB-simulation-archive`

## 1. 结论摘要

- **协议端到端跑通**: 两个体系都完整拉到目标 ≈55 Å(弹簧末端几乎松弛,Δr<0.2 Å),S1 尾与 S2 头充分分离。
- **初筛协议正常**,但核验发现 **3 处必须修订后才能投定量(1 Å/ns)**——均已在本轮修订包中完成(见 §4)。
- 核心科学信号: **cleaved 界面在 29–30 Å 早期整体松脱;uncleaved 界面把接触维持到 40–42 Å 才大规模断开。两者解离峰力接近(≈1.0–1.1 nN 量级),但 uncleaved 的接触网络更延展、总功更高。**

## 3. 科学解读

**cleaved —— 界面早期整体滑脱。** 各段功单调递减(30→1 kcal/mol),力峰值出现在
拉开仅 1 Å 的 29.08 Å 处,30.13 Å 即"解离完成"。这说明 S2′ 切断后,S1 尾与 S2 头的
跨链界面(盐桥 ASP614…LYS854 等)在很小的分离下就整体脱开,后续拖动几乎无阻力。
总功 71.1 kcal/mol 主要贡献来自前 5 Å 的脱开过程。

**uncleaved —— 完整界面延展抵抗。** 段功非单调(峰在段 1–2,即 34–44 Å 区间),
力峰值出现在 40.73 Å,42 Å 附近才完成解离。未切割的 S2′ 保持了更长的界面接触
网络,解离发生在更大的分离处。总功 96.0 kcal/mol,较 cleaved 高 ~35%。

**峰力对比要谨慎。** 5 Å/ns 是初筛拉速,快拉会让峰值力偏高(粘弹性偏置);两者
1068/1016 pN 的接近是初筛分辨率的巧合性结果,真正的解离峰力对比以 1 Å/ns
定量为准。做功差(297.7 vs 401.7 kJ/mol)同样会在慢拉下重新归一。

**初筛 vs 定量的论文角色(证据边界)。** 初筛(5 Å/ns)的定位是**协议验证 +
假设生成**,不进论文证据链;其已知瑕疵(快拉力偏置、开局压缩伪迹、chunk00 截断
缺口)也因此不影响可信度——论文的数字证据全部来自 1 Å/ns 定量运行(从 eq4 全新
起跑,全部段完整完成)。初筛最多以两种身份出现在论文:(a) Methods 一句"以
5 Å/ns 先行排查协议、再降速至 1 Å/ns 生产";(b) 若定量后两档拉速的定性排序
一致,作为"结论对拉速稳健"的支撑表述(加分项)。若不一致,一律以定量为准,
初筛不提。

## 4. 发现的问题与修订(定量前必做)

### 4.1 反应坐标起点 R0 与平衡距离不匹配(主要问题)
两体系 eq4 平衡 COM 距离分别是 28.28 Å(cleaved)与 31.27 Å(uncleaved),而
smd.RST 起点硬编码 28.80 Å。后果:
- uncleaved 开局弹簧被**压缩 2.47 Å**,产生 −35.6 kcal/mol/Å ≈ **2475 pN** 的
  初始"力峰"——这是装载伪迹(前 ~50 ps 弹簧在把界面往回推),被初筛误报为
  "最大拉力",**不是解离力**。排除后真实拉伸峰为 1016 pN @ 40.73 Å。
- cleaved 也有 +0.52 Å 的轻微预拉伸(力 +7.5)。

**修订**: 各体系 R0 改为自身平衡距离(cleaved 28.28 / uncleaved 31.27),弹簧
开局松弛、力谱干净。脚本已改为从 smd.RST 读 R0,直接改 r2/r3 即生效。

### 4.2 断点续跑会静默跳过截断段(cleaved chunk00 实证)
cleaved chunk00 的 mdout 止于 NSTEP=482000(未达 500000,无 `Final Performance
Info:`,进程被杀),但 ntwr=20000 已写 rst7,旧脚本只看 rst7 存在 → 重启时静默
跳过,合并后的 smd.out 在 33.6→33.8 Å 处有 ~36 ps 缺口(位移差 0.18 Å)。
初筛可接受,定量不可。**修订**: 跳过条件改为 rst7 + mdout 正常完成 + 段目标一致
三者齐备;截断段自动删除、从上一完整段重跑。

### 4.3 analyze_smd.py 段边界误判
负功瞬态(开局压缩)被 `diff(w)<-1` 误判为段重置 → uncleaved 误报 7 段,累计功
虚高 1.4 kcal/mol(97.4 vs 真值 96.0)。**修订**: 重置判据增加"掉落后落在 0 附近";
解离峰值改看拉伸正力;R0 从数据首行读取。

## 5. 定量运行方案(修订包部署后)

| | cleaved | uncleaved |
|---|---|---|
| R0 → RF | 28.28 → 55.0 Å | 31.27 → 55.0 Å |
| 拉速 | 1 Å/ns | 1 Å/ns |
| 时长 | 26.72 ns | 23.73 ns |
| 分片 | 27 × 1 ns(尾 0.72 ns) | 24 × 1 ns(尾 0.73 ns) |
| 命令 | `bash run_smd_cleaved.sh --smd-speed 1 --engine=pmemd.cuda` | `bash run_smd_uncleaved.sh --smd-speed 1 --engine=pmemd.cuda` |

建议在**各自独立的 amber 目录**运行(两体系同时跑需 2 卡或分时;单卡建议先后)。

**可选**: 若想先拿一版干净的定性力谱,可先按新 R0 重跑一次 5 Å/ns 初筛
(cleaved 6 段 / uncleaved 5 段),再投定量——非必须。

**跑完后**: `python analyze_smd.py smd.out --speed 1 --plot`,推 GitHub,云侧复核
力-位移曲线与功。
