# 七、命名规则(修订后)

1. **顶层状态文件不挂版本**: README.md / NODES.md / 各 PROGRESS.md / 各 USAGE.md 持续追加更新, 无 `_vNN`。
2. **科研产物挂 `vNN`**: 脚本、mdin、RST、PDB、数据、图、报告用 `<逻辑名>_<体系>_<vNN>.<ext>`; 每次实质修改 +1, 禁止覆盖。
3. **体系标识**: 体系相关文件名一律含 `cleaved` / `uncleaved`(目录隔离 + 文件名双重标识); 与体系无关(对比层/立项层)不加。
4. **01–04 无共享执行文件**: 字节相同也分体系各留一份; 阶段根目录**仅允许双体系综合文档**(报告/PROGRESS/说明), 执行文件必须进体系目录。
5. **交叉引用同步**(D5): mdin 的 `DISANG` 行、脚本引用的 mdin/RST 名迁移时同步改成带版本新名(如 `DISANG=smd_cleaved_v02.RST`); 迁移后跑一致性检查确认零悬空引用。
6. **USAGE 粒度**: 目录 USAGE.md 内**按文件逐一建条目**(用途/适用体系/输入/输出/调用方式/限制/已知问题), 不写笼统目录说明。
