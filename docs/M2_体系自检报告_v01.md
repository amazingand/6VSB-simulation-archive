## 3. 关键解答:VDW 7.67E12 到底是什么

之前诊断"疑似 CHARMM 对糖原子命名的力场分配伪影"——**这个判断要修正**。云侧自检找到了真正的根因:

1. 用 parm7/rst7 做 sander 极小化,**初始能量恰好就是 7.6729E+12**,和 CHARMM-GUI 里的数值一样;
2. 最大梯度定位在 **OT2(原子 1968)**——它是 **cleaved 体系 S2′ 切割位点 ARG815(链 A 末端)的 C 端羧基氧**;
3. 切割后 ARG815 的羧基(OT2)与下一条链 SER816 的 N 端氨基初始**重叠在 0.26 Å**(CHARMM-GUI 在切割位点断开肽键、补了末端原子,但坐标还停在原肽键位置上);
4. **sander 极小化第 1 步就把能量从 7.67E12 降到 3.3E10,200 步收敛到 −9.81E5 kcal/mol**,OT2…N 推到 2.82 Å——完全正常。

uncleaved 体系没有切割末端,初始能量**直接就是正常的 −9.08E5 kcal/mol**,作为对照坐实了结论:

> **7.67E12 是 S2′ 切割两末端原子重叠的几何问题,不是力场或拓扑缺陷;标准极小化即可化解。两个体系都健康。**
