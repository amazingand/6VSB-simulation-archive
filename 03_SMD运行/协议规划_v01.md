# M3 里程碑:模拟协议规划 —— SMD 力驱动解离协议框架

> 项目 C′(力驱动 S1/S2 解离 → 融合肽释放)。日期:2026-08-13。基线:CHARMM-GUI 生成的 cleaved/uncleaved 两体系(ff19SB + GLYCAM06j + TIP3P,137³ 立方盒,NaCl 0.15M,自检全绿)。生产引擎:你的 RTX 4070S + pmemd.cuda(Amber 25)。

---

## 0. 一句话

在 CHARMM-GUI 提供的极小化/平衡基础上,**新增一个专门设计的 SMD 力驱动解离协议**(jar=1 距离约束 + COM 拉动),用于把 2023 论文的"静态剪切 S1 剥离"升级为动力学过程;同时给出与云端一致的**对齐极小化**方案,保证本地生产起点与云侧 pilot 完全同步。

## 1. 模式与力梯度(立项已确认,此处落地为参数)

| 模式 | S2′ | S1 处理 | 动力学操作 | 预期 |
|---|---|---|---|---|
| **M1(正)** | 切割(R815↓) | 剥离 | SMD 拉 S1 尾离开 S2 头 | 释放 FP |
| **M2(负·S2′ 闸门)** | 未切割 | 剥离 | SMD 拉 S1 尾离开 S2 头 | 不释放 |
| **M3(负·S1 闸门)** | 切割 | 保留 | 平衡态(不加力) | 不释放 |

力梯度(2×2 因子 + 力水平):{S2′ 切, 未切} × {S1 解离: 不加力/中力/强力}。**M1/M2 用 SMD;M3 就是普通平衡生产。**

## 2. 反应坐标与拉力方向定义(SMD 核心,已 pilot 验证)

**反应坐标**:S1 尾(540–685)→ S2 头(686–1035)的**质心(Cα)距离**,即"S1 是否被剥离"的直接度量。

云侧实测(cleaved/uncleaved 两体系一致,2026-08-13 parm7/rst7 重新核算):
- **S1 尾 = parm res 371–541(PDB 540–685,144 个 Cα)**
- **S2 头 = parm res 0–370(PDB 686–1035,350 个 Cα)**
- **初始 Cα COM 距离 = 28.80 Å**(早期 23.5 Å 为旧估计,已修正)
- 盒半边长 68.5 Å → 拉动上限 55 Å(留安全边界),**位移 = 26.2 Å**

**关键限制(AMBER 硬编码)**:`igr1/igr2` **每组最多 200 个原子**(`IMAXGR`,见 [AMBER 邮件列表](http://archive.ambermd.org/200906/0195.html))。因此 **COM 组用 Cα 子集**:S1 尾全部 144 个 Cα(≤200)+ S2 头 350 个 Cα **均匀采样 200 个**。社区明确建议用尽量少的原子——约束力过于弥散反而失效([同一邮件列表](http://archive.ambermd.org/200906/0195.html))。Cα 采样 COM 与全重原子 COM 相差 <0.3 Å,足够稳健。

**方案 A(主选,已 pilot 验证):COM 距离约束 `iat=-1,-1` + `igr1/igr2`**
在云侧 sander(Amber 26)实测通过:`iat=-1,-1` 被正确解析为两组质心间的距离约束,`jar=1` 恒速拉动从 r2=28.8 线性移到 r2a=55,约束力正常输出。
- **pmemd.cuda 兼容性已确认**:`iat=-1` COM 约束在 **AMBER 18 update.7 起修复支持**([2019 邮件列表](http://archive.ambermd.org/201901/0028.html)),你的 Amber 25 直接可用,无需回退方案 B。

- **方案 B(备选,仅当 A 在 pmemd.cuda 意外失效时)**:单 Cα 原子对距离约束,`iat=两个Cα`。力集中在单原子,已不推荐。

**反应坐标从 28.8 → 55 Å 的理由**:S1 尾与 S2 头完全脱离接触(S1–FP 最小接触 2.7 Å 界面,拉开 >26 Å 后无相互作用),FP(829–855)完全暴露,解离完成判定成立。

## 3. SMD 参数(pmemd.cuda,Amber 25)

**引擎与语法**:`jar=1`(Amber 的 JAR/SMD 距离约束实现)配合 `&rst` 记录、`DISANG` 指定约束文件、`DUMPAVE` 输出拉力与做功。**注意:`jar=1` 只能挂一个 nmropt restraint**(Amber 会报 "In Jarzynsky runs, there must only one restrain"),因此 SMD 阶段**不挂糖二面角 restraint**,仅一个距离约束;蛋白 posres 走 `ntr` 卡(与 jar 兼容,已获社区验证 [2015 邮件列表](http://archive.ambermd.org/201502/0525.html))。

**pilot 实测确认的三个语法要点**(云侧 sander 2026-08-13,否则会白跑):
1. `DISANG`/`DUMPAVE`/`LISTIN`/`LISTOUT` **放在 `&cntrl` 卡外**(与 CHARMM-GUI 一致),且必须带 `&wt type='END' /` 卡——缺 `&wt` 时 sander 报 "No wt namelist with TYPE=END" 并从 mdin 误读约束组;
2. `igr1`/`igr2` 原子列表**不要用 `\` 续行**(Fortran namelist 非法),直接换行、行尾逗号;
3. **NPT 卡必须显式 `ntp=1, barostat=2, pres0=1.0`**(CHARMM-GUI step5 有;仅 `ntb=2` 会被 sander/pmemd 拒绝)。

### 3.1 参数建议表

| 参数 | 值 | 说明 |
|---|---|---|
| **拉速** | **5 Å/ns(初筛)→ 1 Å/ns(定量)** | 与 2023 静态剪切可比性优先;先快扫找解离阈值,再慢拉定量力谱 |
| **力常数 rk2** | **7.2 kcal/mol/Å²(≈ 120 pN/Å 量级)** | Amber SMD 常见默认,保证 ns 尺度完成解离 |
| 反应坐标 | Cα COM 距离 **28.80 Å → 55 Å** | 位移 26.2 Å |
| 单次时长 | 5 Å/ns:5.24 ns;1 Å/ns:26.2 ns | nstlim = 位移/拉速/dt |
| COM 组 | S1尾 144 Cα + S2头 200 Cα(均匀采样) | **每组 ≤200 原子(IMAXGR 硬限制)** |
| 时间步长 | dt = 0.002 ps(生产) | 沿用 CHARMM-GUI step5 |
| 温度/压力 | 310.15 K,Langevin γ=1.0;1 bar,NPT | 沿用 |
| 输出 | 每 1000 步 DUMPAVE;每 10000 步坐标 | 力/功曲线解析 |

**拉速换算公式**:`nstlim = (r2a − r2) / (v × dt)`,其中 r2=28.80、r2a=55、dt=0.002 ps。
- 5 Å/ns:v=0.005 Å/ps → nstlim = 26.2 / (0.005 × 0.002) = **2,620,000 步**(5.24 ns)
- 1 Å/ns:v=0.001 Å/ps → **13,100,000 步**(26.2 ns)

### 3.2 mdin 骨架(jar=1 + ntr,已 pilot 验证,交付即用)

```
SMD 恒速拉动: jar=1 COM 约束, 5 A/ns, nstlim=2,620,000 (5.24 ns), dt=0.002
 &cntrl
    imin=0, irest=1, ntx=5,
    nstlim=2620000, dt=0.002,
    ntc=2, ntf=2, cut=12.0, fswitch=10.0,
    ntb=2, ntp=1, barostat=2, pres0=1.0,
    ntt=3, gamma_ln=1.0, temp0=310.15,
    ntr=1, nmropt=1, jar=1,
    ntpr=1000, ntwx=10000, ntwr=20000, ntxo=2, ioutfm=1, iwrap=1,
    watnam='WAT', owtnm='O',
 /
 &ewald
    vdwmeth = 0,
 /
 &wt
    type='END'
 /
DISANG=smd.RST
DUMPAVE=smd.out
LISTIN=POUT
LISTOUT=POUT
Protein posres
1.0
RES 1 151 152 371
END
END
```

要点:`jar=1` 挂唯一距离约束(不挂糖 dihe);`ntr` 蛋白 posres **只锚定 S2 头**(解离过程 S1 尾必须自由移动)。posres 段:
- **cleaved**:`RES 1 151 152 371`(S2 头 = res 1–370,在 S2′ 切割处断成 1–151 / 152–370 两段)
- **uncleaved**:`RES 1 371`(整条 S2 头 res 1–370,不断)

### 3.3 约束文件 smd.RST(方案 A,COM Cα 采样,交付即用)

```
SMD COM restraint (cleaved): S1tail vs S2head C-alpha
&rst
  iat = -1,-1,
  r1 = 0.0, r2 = 28.80, r3 = 28.80, r4 = 55.0,
  rk2 = 7.2, rk3 = 7.2,
  r2a = 55.0, rk2a = 7.2, rk3a = 7.2,
  igr1 = 5810,5824,5844,5858,...,7954,      ! S1 尾 144 个 Cα(实际 parm 原子序号)
  igr2 = 5,32,53,70,...,5800,               ! S2 头均匀采样 200 个 Cα
&end
```

(上面 igr 原子序号为 cleaved 版实际值,截取展示;完整列表见交付的 `smd.RST`。uncleaved 版 S2 头不断链,igr2 为另一组采样序号。)

**参数含义**:`iat=-1,-1` + `igr1/igr2` 即"两组质心距离";r2=r3=28.80 为起始平衡距离,rk2=rk3=7.2 为力常数,r2a=55.0 为目标距离,Amber 自动从 r2 线性移到 r2a(jar=1 恒速拉动)。Cα 组已满足每组 ≤200(IMAXGR)。**此文件与 mdin 均已用云侧 sander 逐字验证(100 步 pilot),本地 pmemd.cuda 直接可用。**

### 3.4 方案 B 备选(单原子对,仅在 A 于 pmemd.cuda 意外失效时用)

```
&rst
  iat = <S1尾远端Cα序号>, <S2头近界面Cα序号>,
  r1 = 0.0, r2 = <当前两Cα距离>, r3 = <同r2>, r4 = 55.0,
  rk2 = 7.2, rk3 = 7.2,
  r2a = 55.0, rk2a = 7.2, rk3a = 7.2,
&end
```

> 方案 A 已确认可行且 pmemd.cuda 从 AMBER 18 update.7 起支持 `iat=-1` COM 约束,方案 B 仅作保险保留,不另外交付文件。

## 4. 平衡协议(在 CHARMM-GUI 基础上调整)

CHARMM-GUI 的 `step4.1_equilibration`(NVT 125 ps,dt=1fs,posres 1.0 + 糖二面角)直接进入 `step5` 生产。**建议调整**:

| 阶段 | 内容 | 时长 | 说明 |
|---|---|---|---|
| **EQ1** | NVT 0→310 K,posres 蛋白 2.0,糖 dihe | 100 ps | 缓慢升温,沿用 CHARMM-GUI 约束体系 |
| **EQ2** | NPT 310 K,posres 蛋白 2.0→1.0,糖 dihe | 200 ps | 逐步放开蛋白约束 |
| **EQ3** | NPT 310 K,posres 0.5,糖 dihe | 200 ps | 弱约束 |
| **EQ4** | NPT 310 K,无 posres,保留糖 dihe | 500 ps | 无约束平衡,体系自洽 |
| **EQ5(可选)** | NPT 310 K,无约束 | 500 ps | 稳定性检验(对照) |

> 关键调整点:CHARMM-GUI 是"1 步平衡 + 直接生产";我加为**阶梯放开约束**(2.0→1.0→0.5→0),避免 S1/S2 界面在平衡初期被强约束锁死、后期突然放开导致的应力。糖二面角 restraint 全程保留(聚糖构象需要)。

## 5. 对齐极小化(云端/本地一致性,你第 3 点)

**目标**:本地生产起点与云侧完全一致。

**原理**:极小化是**确定性算法**(无随机数)——相同 parm7/rst7 + 相同 mdin,收敛坐标与最终能量一致。

**方案(2026-08-14 定为"能量轨迹对齐",替代云侧完整 5000 步复跑)**:
1. **云侧只跑前 100 步**,建立**基准能量轨迹**(sander 完整 5000 步需 ~3 小时,你的 4070S 只需几分钟;跨引擎对比最终能量即可,不必云侧复跑全程);
2. 你本地跑 `align_min.mdin`(完整 5000 步)→ `align_min.rst7` + `align_min.mdout` 更新到 GitHub;
3. 我拉取你的 `mdout`,与云侧基准轨迹**逐点对比前 100 步能量**——趋势与量级一致(前 5–6 位有效数字)即证明两端工具链等价,确定性保证后续各步也一致 → 分界点确认;
4. 之后所有平衡/SMD 都以这个 `align_min.rst7` 为起点,云端 pilot 与本地生产从同一点出发,轨迹可比。
